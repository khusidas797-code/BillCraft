# BillCraft :- Freelancer Invoice Generator.

# Description :- A professional and responsive invoice generator built for freelancers and small businesses using HTML, CSS, and JavaScript.

# Features:-
- Responsive design for desktop, tablet, and mobile
- Professional invoice dashboard UI
- Create and manage invoices
- Automatic invoice number generation
- Invoice date and due date
- Multiple currency options
- Freelancer/business information
- Client information
- Logo upload and live preview
- Add and remove services or invoice items
- Automatic quantity × rate calculation
- Automatic subtotal calculation
- Tax calculation
- Discount calculation
- Automatic grand total
- Payment information section
- Notes and payment terms
- Save invoice drafts using browser

# Technologies Used :-
- HTML5 - Structure and semantic content
- CSS3 - Responsive layout, styling, cards, buttons, and print design
- JavaScript - Dynamic invoice generation, calculations, local storage, interactions, and live preview
- Git & GitHub - Version control and project hosting
- GitHub Pages - Deployment
